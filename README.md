# Super Powers (Forge 1.17.1)

Keys (Controls -> "Super Powers"):
G - Dash, R - Power Punch, V - Ground Slam, B - Toggle Flight (survival only)

Build (JDK 17, Gradle 7.3.3):
  gradle build
Result: build/libs/superpowers-1.0.0.jar -> mods/ (Forge 37.1.1+, Minecraft 1.17.1)
Or push to GitHub: Actions builds the jar automatically (artifact "superpowers-jar").
